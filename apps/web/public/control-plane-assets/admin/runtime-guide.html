Runtime Setup Guide

A Runtime is the app builder users choose when creating a project. As an admin, you need a name, a Runtime Config, and any Secrets or environment variables that Runtime expects.

Before You Add a Runtime

  1. Confirm the Runtime provider has published a Docker image for your server CPU architecture.
  2. Confirm the image starts a Runtime Service that implements Runtime Protocol v3.
  3. Confirm the Runtime Service can clone, commit, and push to the project source repository during runs.
  4. Create any required credentials in Admin, then Secrets.
  5. Ask the Runtime provider which Runtime Secret names and environment variables it expects.

Add the Runtime

  1. Open Admin, then Runtimes.
  2. Click Add Runtime.
  3. Enter a user-facing name, such as Milky.
  4. Paste the Runtime Config JSON.
  5. Enable it when ready. Optionally make it the default for new projects.

Secret Example

Create a Secret named builder_api_key, then bind it to the opaque Runtime Secret name expected by the image: 

{
  "config_version": 3,
  "launcher": {
    "kind": "docker",
    "image": "docker.io/moonbitcloud/mooncraft-agent-runtime:0.4.0"
  },
  "env": {
    "MODEL": "gpt-5.4-mini"
  },
  "secrets": [
    {
      "source": "builder_api_key",
      "name": "builder_api_key"
    }
  ]
}

Account File Secret Example

If the Runtime expects account-file content, create a Secret whose value is the complete file contents, then bind it to the opaque name documented by the Runtime provider: 

{
  "config_version": 3,
  "launcher": {
    "kind": "docker",
    "image": "docker.io/moonbitcloud/mooncraft-agent-runtime:0.4.0"
  },
  "env": {},
  "secrets": [
    {
      "source": "builder_account_file",
      "name": "builder_account_file"
    }
  ]
}

The Runtime Service decides how to use that value during initialization. MoonCraft does not know whether it is a file, API key, account token, or another credential.

Env Example

Use env only for non-secret strings required by the Runtime image: 

{
  "config_version": 3,
  "launcher": {
    "kind": "docker",
    "image": "docker.io/acme/custom-runtime:1.0.0"
  },
  "env": {
    "RUNTIME_MODE": "production"
  },
  "secrets": [
    {
      "source": "mooncraft_ai_api_key",
      "name": "builder_api_key"
    }
  ]
}

Field Reference

  • launcher.kind: currently only docker is supported.
  • launcher.image: the Docker image MoonCraft runs.
  • env: optional non-secret environment variables passed to the Runtime launcher.
  • secrets.source: the Admin Secret name.
  • secrets.name: the opaque Runtime Secret name sent to the Runtime Service during initialization.
Runtime Config does not include first-class agent names, model fields, command lines, container users, provider fields, preview URLs, or deployment host names. Those details belong inside the Runtime implementation, semantics-free env, or MoonCraft platform code. The Runtime Service HTTP protocol lives in docs/runtime-protocol/.
