Runtime Setup Guide

A Runtime tells MoonCraft which app-building environment to use. As an admin, you need a user-facing Runtime name, a container image tag, a Runtime JSON block, and any secrets referenced by that JSON.

Before You Add a Runtime

  1. Get a container image tag from the Runtime provider, for example docker.io/moonbitcloud/mooncraft-runtime-codex-mini:latest.
  2. Confirm that the image is available to the MoonCraft host and supports the CPU architecture used by your deployment.
  3. Ask the Runtime provider for the exact Runtime JSON and the names of any required secrets.
  4. Create the required secrets in Admin before enabling the Runtime for users.

Create Secrets

  1. Open Admin, then Secrets.
  2. Click Add secret.
  3. Enter the secret source name that the Runtime JSON will reference.
  4. Choose file for account files such as auth.json, or text for plain values.
  5. Paste the full secret value and save it.

Add the Runtime

  1. Open Admin, then Runtimes.
  2. Click Add Runtime.
  3. Enter a short user-facing name, such as Codex or Kimi.
  4. Paste the Runtime JSON provided for the image.
  5. Choose whether the Runtime is enabled and whether it should be the default.
  6. Click Create.

Codex Account Example

To add a Runtime named Milky that uses Codex account auth, create a file secret named milky_codex_auth whose value is the full contents of $HOME/.codex/auth.json. Then use this Runtime JSON: 

{
  "protocol_version": 1,
  "image": "docker.io/moonbitcloud/mooncraft-runtime-codex-mini:latest",
  "agent": "codex",
  "model": "codex-account",
  "provider": "codex",
  "send": ["mooncraft-runtime-send"],
  "container_home": "/root",
  "secrets": [
    {
      "source": "milky_codex_auth",
      "file": ".codex/auth.json"
    }
  ]
}

OpenRouter Key Example

{
  "protocol_version": 1,
  "image": "registry.example.com/mooncraft/codex-runtime:2026-05",
  "agent": "codex",
  "model": "openai/gpt-5.4-mini",
  "provider": "openrouter",
  "send": ["mooncraft-runtime-send"],
  "container_home": "/root",
  "secrets": [
    {
      "source": "admin_openrouter_key_pool",
      "env": "MOONCRAFT_AI_API_KEY"
    }
  ]
}

What the Fields Mean

  • image: the container image MoonCraft will run.
  • agent, model, and provider: labels shown to admins and used for Runtime metadata.
  • send: the command inside the container that receives a MoonCraft task.
  • container_home: the home directory used inside the container.
  • secrets[].env: injects a secret as an environment variable.
  • secrets[].file: writes a file under container_home before the Runtime starts.
If a Runtime fails immediately after being added, first check that the image tag is reachable from the MoonCraft host and that every secret source named in the JSON exists.
