Runtime Setup Guide

A Runtime is the app builder users choose when creating a project. As an admin, you need a name, a Runtime Protocol v3 Docker image tag, and any Secrets or environment variables that image expects.

Before You Add a Runtime

  1. Confirm the Runtime provider has published an image for your server CPU architecture.
  2. Confirm the image exposes a Runtime Service on container port 8080 and a preview service on 4792.
  3. Create the credential in Admin, then Secrets.
  4. Ask the Runtime provider which Secret targets and environment variables the image expects.

Add the Runtime

  1. Open Admin, then Runtimes.
  2. Click Add Runtime.
  3. Enter a user-facing name, such as Milky.
  4. Paste the Runtime JSON.
  5. Enable it when ready. Optionally make it the default for new projects.

Environment Secret Example

Create a Secret named builder_api_key, then bind it to the environment variable expected by the image: 

{
  "protocol_version": 3,
  "image": "docker.io/moonbitcloud/mooncraft-agent-runtime:0.4.0",
  "env": {
    "MODEL": "gpt-5.4-mini"
  },
  "secrets": [
    {
      "source": "builder_api_key",
      "target": {
        "type": "env",
        "name": "BUILDER_API_KEY"
      }
    }
  ]
}

File Secret Example

If the Runtime image expects a file credential, create a Secret whose value is the complete file contents, then bind it under /home/mooncraft: 

{
  "protocol_version": 3,
  "image": "docker.io/moonbitcloud/mooncraft-agent-runtime:0.4.0",
  "env": {},
  "secrets": [
    {
      "source": "builder_account_file",
      "target": {
        "type": "file",
        "path": ".codex/auth.json"
      }
    }
  ]
}

Env Example

Use env only for non-secret strings required by the Runtime image: 

{
  "protocol_version": 3,
  "image": "docker.io/acme/custom-runtime:1.0.0",
  "env": {
    "RUNTIME_MODE": "production"
  },
  "secrets": [
    {
      "source": "mooncraft_ai_api_key",
      "target": {
        "type": "env",
        "name": "BUILDER_API_KEY"
      }
    }
  ]
}

Field Reference

  • image: the Docker image MoonCraft runs.
  • env: optional non-secret environment variables injected into the Runtime Service container.
  • secrets.source: the Admin Secret name.
  • secrets.target: where MoonCraft injects that Secret inside the Runtime container.
Runtime JSON does not include agent names, model names, command lines, container users, provider fields, preview URLs, or deployment host names. Those details belong inside the Runtime image or MoonCraft platform code.
