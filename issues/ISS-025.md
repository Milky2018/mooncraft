# ISS-025: Make Runtime Protocol a shared MoonBit package

## Metadata
- Type: task
- Status: open

- Assignee: unassigned
- Created: 2026-06-01

## Description
Runtime Protocol v3 is currently implemented as duplicated DTOs, route strings, status values, and error rules across documentation, the control-plane Runtime Service client, and the official Runtime Service. This makes endpoint and state-machine drift hard to catch until Docker image or test-environment failures.

The concrete failure that exposed this is the test Runtime returning `Runtime endpoint not found.` for `POST /init` while still accepting `/exec` before initialization. MoonCraft needs a compiled, shared protocol package so client and server cannot silently diverge on protocol-visible behavior.

## Design
Create `packages/runtime-protocol` as the MoonBit source of truth for Runtime Protocol v3. Put DTOs, route constants/builders, Runtime Error shape, protocol-visible status values, JSON encode/decode helpers, and protocol validation there.

Refactor the control-plane Runtime Service client and the official Runtime Service to depend on that package. Keep HTTP client/server transport, Docker launcher logic, source-host integration, Codex execution, preview serving, and Runtime Service private state out of the shared package.

Split the official Runtime Service enough that protocol handler tests can run without Docker, GitHub, or real Codex. Keep Docker image checks as final black-box smoke tests.

## Acceptance Criteria
- [ ] `packages/runtime-protocol` exists and contains Runtime Protocol v3 DTOs, routes, Runtime Error shape, protocol-visible status values, JSON helpers, and protocol validation.
- [ ] Control-plane Runtime Service client uses `packages/runtime-protocol` instead of locally duplicated Runtime Protocol DTOs and route strings.
- [ ] Official Runtime Service uses `packages/runtime-protocol` instead of locally duplicated Runtime Protocol DTOs and route strings.
- [ ] Protocol-visible state rules are covered by contract tests, including `/exec` before `/init` returning `409`, `/init` making `/health` ready, idempotent `/exec`, readable `/runs/{run_id}`, event cursor semantics, and terminal success requiring `ready_commit_sha`.
- [ ] OpenAPI remains documentation and has a lightweight drift check against protocol endpoints, methods, and status enums.
- [ ] Docker runtime image check remains a final black-box smoke test and is not the only test that can catch protocol drift.
- [ ] `moon check --warn-list +73`, relevant package tests, and smoke checks pass.
