## Description
Move project source storage from the v2 workspace snapshot/scratch model to v3 Docker named volumes. `/workspace` becomes the authoritative project source storage, and `/home/mooncraft` becomes Runtime-private durable state.

## Design
Create per-project Docker named volumes for workspace and Runtime home. Remove normal run-finalization workspace snapshots from the active flow. Add explicit migration or reset behavior for existing projects. Admin inspect/download should be implemented outside Runtime Protocol through helper-container access to the workspace volume if needed.

## Acceptance Criteria
- [x] New projects receive durable Docker named volumes for `/workspace` and `/home/mooncraft`.
- [x] Run finalization no longer archives the workspace as the authoritative source state.
- [x] Existing project data has an explicit migration, import, or reset path.
- [x] Project deletion removes the associated Runtime volumes.
- [x] Documentation states backup and restore expectations for Runtime volumes.
