# ISS-005: Move preview serving behind Runtime Service

## Metadata
- Type: feature
- Status: closed
- Priority: 1
- Labels: runtime, preview, backend
- Assignee: unassigned
- Created: 2026-05-27
- Updated: 2026-05-27
- External ref: none

## Description
Replace control-plane-spawned project preview scripts with Runtime-owned preview serving on fixed container port `4792`.

## Design
On preview request, ensure the project's Runtime Service is ready, call Runtime Service `POST /serve`, and proxy the public Preview Origin to Runtime Service `GET /preview/...` only when serve returns `200`. Delete automatic preview repair from the control-plane flow. Non-2xx serve responses should surface the Runtime Error message to the user.

## Acceptance Criteria
- [x] Control-plane no longer starts `./mooncraft-preview.sh` as a child process in the active v3 preview path.
- [x] Public preview requests proxy to the Runtime container's port `4792`.
- [x] Successful preview start requests refresh the Runtime Idle TTL.
- [x] Failed preview readiness does not refresh the TTL and returns a user-facing error message.
- [x] Preview repair prompts and bounded repair loops are removed from the active v3 flow.
