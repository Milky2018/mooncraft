# ISS-002: Migrate Runtime manifests to v3

## Metadata

## Description
Replace the v2 `RuntimeSpec` shape with the v3 manifest shape: `protocol_version`, `image`, and optional semantics-free `secrets`. Remove control-plane knowledge of `agent`, `model`, `auth`, provider kinds, and v2 forbidden-field logic from active parsing.

## Design
Update SDK parsing, validation, default manifest JSON, built-in Runtime files, admin Runtime save/load paths, and any tests that assert v2 fields. Keep file secret targets relative to `/home/mooncraft`; allow missing `secrets` as an empty list; reject additional fields.

## Acceptance Criteria
- [ ] Runtime manifest parsing accepts v3 manifests matching `docs/runtime-protocol/runtime-manifest.v3.schema.json`.
- [ ] Runtime manifest parsing rejects extra fields such as `agent`, `model`, `auth`, `send`, and `container_user`.
- [ ] Built-in Runtime definitions use protocol version 3 and no longer expose agent/model/auth fields.
- [ ] Existing tests are updated or replaced with v3-focused coverage.
