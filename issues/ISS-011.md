## Description
Add the Project Source Repository model and the first Source Host adapter. GitHub is the temporary Source Host implementation; the domain model should stay source-host-neutral so MoonHub can replace it later.

## Design
Store repository identity, owner/name or provider id, clone URL, default branch, current Ready Source Commit, and source connection status. Project creation should create an empty user-owned repository. Deleting a MoonCraft project must not delete the repository. If the repository is unavailable or unauthorized, the project should enter Source Disconnected instead of silently creating replacement source storage.

## Acceptance Criteria
- [ ] Project creation creates an empty user-owned Project Source Repository through the current Source Host.
- [ ] Project metadata stores repository identity, default branch, and current Ready Source Commit.
- [ ] Project deletion leaves the user-owned repository intact.
- [ ] Missing, renamed, transferred, or unauthorized repositories surface a Source Disconnected state.
- [ ] Tests cover create, reconnect/unavailable detection, and delete-without-repository-delete behavior.
