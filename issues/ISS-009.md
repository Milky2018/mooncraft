## Description
`just smoke` no longer reaches the fake builder flow when the database has no enabled Runtime. Project creation returns `422` with `No enabled Runtime is configured.` This makes the local fake-runtime smoke script stale after Runtime Protocol v3 removed repository-seeded built-in Runtime definitions.

## Design
Update the smoke setup so it explicitly configures the Runtime state needed by the fake-runtime path, or replace the old fake-runtime smoke with a Runtime Protocol v3 service fixture. Keep the smoke path free of real provider credentials.

## Acceptance Criteria
- [ ] `just smoke` passes on a clean local database without real provider credentials.
- [ ] The smoke path exercises Runtime Protocol v3 preview readiness instead of control-plane preview scripts.
- [ ] The script no longer asserts v2-only workspace paths or local preview process behavior.
