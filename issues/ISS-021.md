## Description
On `craft-test.moonbitlang.com`, creating a project can fail with a raw nginx HTML response:

```text
Failed to create project. <html>
 <head><title>502 Bad Gateway</title></head>
 <body>
 <center><h1>502 Bad Gateway</h1></center>
 <hr><center>nginx/1.18.0 (Ubuntu)</center>
 </body>
 </html>
```

This is not an acceptable user-facing error. It indicates that the create-project path can currently surface infrastructure failure bodies directly to the UI, and may also be doing enough synchronous work during project creation to hit an upstream/proxy failure.

## Design
Diagnose the real 502 source first. The fix should address the root cause in the project creation path, not only mask the message. Expected source/runtime failures should return MoonCraft JSON API errors with actionable messages. The frontend API client should also sanitize non-JSON HTML error bodies from gateways so users never see raw HTML.

## Acceptance Criteria
- [x] Reproduce or identify the exact upstream step that returns 502 during project creation on the test deployment.
- [x] Expected project creation failures return a JSON `ApiErrorResponse`, not nginx/raw HTML.
- [x] The frontend displays a short product-level message for non-JSON 5xx responses, such as "MoonCraft is temporarily unavailable. Please try again."
- [x] Create-project flow does not expose raw HTML response bodies in notices.
- [x] Regression coverage verifies non-JSON 502 bodies are sanitized.

## Close Notes
- 2026-06-01: Project creation no longer synchronously prepares or initializes Runtime Service storage. The create path now creates the Project Source Repository first, returns a JSON `Conflict` product error when GitHub repository access is not connected, persists source metadata after project creation, and starts Runtime later through the run/preview paths. The web API client now sanitizes non-JSON 5xx gateway bodies into a product-level temporary-unavailable message. Verified with `moon check --warn-list +73`, `moon test apps/web/shared --warn-list +73`, `moon test apps/web --warn-list +73`, `moon test services/control-plane --warn-list +73`, `moon test --warn-list +73`, and `just smoke`.
