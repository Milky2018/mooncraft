## Description
Add the Runtime Service initialization flow required by ADR-0007. MoonCraft must initialize a Runtime Service with source repository access and Runtime Secrets before exec, preview, status, or event operations.

## Design
After the Runtime Launcher provides a reachable Runtime Service, call `GET /health`; then call `POST /init` with project id, Project Source Repository URL/default branch/current commit, a short-lived Project Source Credential, and resolved Runtime Secrets. Treat `not_initialized` as a normal pre-init service state. Retry `/init` when safe, but never reinitialize while a Run is active.

## Acceptance Criteria
- [ ] Runtime Service ensure flow calls `POST /init` before `/exec`, `/runs`, `/runs/{run_id}/events`, or `/preview/`.
- [ ] `/init` payload uses source repository fields, source credential fields, and opaque Runtime Secret name/value payloads.
- [ ] Runtime Secrets are no longer materialized through Docker env/file targets in the active protocol path.
- [ ] Active Run conflicts from `/init` map to a clear user/admin error.
- [ ] Tests cover healthy uninitialized service, successful init, init retry, active-run conflict, and secret resolution.
