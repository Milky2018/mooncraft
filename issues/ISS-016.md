## Description
Update the official Docker-backed Runtime Service to implement the ADR-0007 source-host-backed protocol. It must initialize from a Project Source Repository, use provided credentials, commit and push successful source changes, and serve preview under `/preview/`.

## Design
Install and use `git` inside the Runtime image. Implement `POST /init` by cloning or updating the repository with the provided short-lived credential and opaque Runtime Secrets. Implement `/exec` so successful source-modifying runs commit and push to the default branch, return `ready_commit_sha`, avoid force push, and fail on unresolved conflicts. Serve generated preview content under `/preview/`.

## Acceptance Criteria
- [x] Official Runtime Service implements `GET /health`, `POST /init`, `POST /exec`, `GET /runs/{run_id}`, `GET /runs/{run_id}/events`, and `/preview/`.
- [x] Runtime can clone an empty repository and generate the first source commit.
- [x] Runtime commits and pushes source changes before returning `succeeded`.
- [x] Runtime returns final `ready_commit_sha` for succeeded Runs.
- [x] Runtime serves preview under `/preview/` without relying on port `4792`.
- [x] Runtime conformance smoke covers init, exec, events, commit push, and preview.
