# ISS-017: Remove legacy Docker volume and workspace archive protocol paths

## Metadata
- Type: task
- Status: open
- Priority: 2
- Labels: runtime, cleanup, persistence, migration
- Assignee: unassigned
- Created: 2026-05-30
- Updated: 2026-05-30
- External ref: docs/adr/0007-use-source-host-backed-runtime-protocol.md

## Description
Remove active product dependencies on Docker workspace/home volumes, workspace archive persistence, file secret bundles, and fixed Runtime-internal filesystem paths after the source-host-backed flow is implemented.

## Design
Delete or isolate code that creates `mooncraft-workspace-*` and `mooncraft-home-*` volumes for active projects, imports legacy snapshots into Runtime containers, copies file secrets into containers, or treats workspace snapshots as normal Runtime source state. Keep only explicit migration or legacy-inspection paths that are still needed and clearly labeled.

## Acceptance Criteria
- [ ] Active project creation no longer creates Runtime workspace/home Docker volumes.
- [ ] Active Runtime startup no longer mounts workspace/home volumes or file secret bundles.
- [ ] Active flow no longer imports legacy workspace snapshots into Runtime containers.
- [ ] Project deletion does not delete user-owned Project Source Repositories.
- [ ] Docs and tests no longer describe Docker volumes as authoritative source storage.
