# ISS-012: Replace Runtime Manifest with Runtime Config

## Metadata

## Description
Replace active Runtime Manifest parsing and UI language with Runtime Config. Runtime Config is MoonCraft launcher configuration, not Runtime Protocol. The first supported launcher is Docker.

## Design
Update SDK parsing, validation, admin APIs, admin UI copy, tests, database migrations, and smoke setup from `protocol_version` plus `image` manifests to `config_version` plus `launcher`. Keep `env` as non-secret launcher/runtime configuration. Keep `secrets` as named opaque Runtime Secret bindings that are later resolved into `POST /init` payloads.

## Acceptance Criteria
- [ ] Runtime Config parsing accepts `config_version: 3` with `launcher.kind: "docker"` and `launcher.image`.
- [ ] Active validation rejects old Runtime Manifest-only fields and unknown launcher kinds.
- [ ] Admin UI and API copy consistently say Runtime Config, not Runtime Manifest.
- [ ] Existing runtime rows are migrated or reset without compatibility shims in active code.
- [ ] Tests cover valid config, unknown fields, unsupported launcher kinds, env validation, and secret binding validation.
