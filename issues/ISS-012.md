# ISS-012: Replace Runtime Manifest with Runtime Config

## Metadata
- Type: task
- Status: closed
- Priority: 1
- Labels: runtime, config, sdk, admin, migration
- Assignee: unassigned
- Created: 2026-05-30
- Updated: 2026-06-01
- External ref: docs/runtime-protocol/runtime-config.v3.schema.json

## Description
Replace active Runtime Manifest parsing and UI language with Runtime Config. Runtime Config is MoonCraft launcher configuration, not Runtime Protocol. The first supported launcher is Docker.

## Design
Update SDK parsing, validation, admin APIs, admin UI copy, tests, database migrations, and smoke setup from `protocol_version` plus `image` manifests to `config_version` plus `launcher`. Keep `env` as non-secret launcher/runtime configuration. Keep `secrets` as named opaque Runtime Secret bindings that are later resolved into `POST /init` payloads.

## Acceptance Criteria
- [x] Runtime Config parsing accepts `config_version: 3` with `launcher.kind: "docker"` and `launcher.image`.
- [x] Active validation rejects old Runtime Manifest-only fields and unknown launcher kinds.
- [x] Admin UI and API copy consistently say Runtime Config, not Runtime Manifest.
- [x] Existing runtime rows are migrated or reset without compatibility shims in active code.
- [x] Tests cover valid config, unknown fields, unsupported launcher kinds, env validation, and secret binding validation.
