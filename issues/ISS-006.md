## Description
Create an official Runtime image that implements Runtime Protocol v3. The image should hide any Codex, Claude, model, provider, or account details behind its Runtime Service implementation.

## Design
Add a small HTTP Runtime Service inside the runtime image. It listens on `8080`, implements `/health`, `/exec`, `/runs/{run_id}`, `/runs/{run_id}/events`, and `/preview`, runs the underlying builder internally, emits structured events, owns preview startup on `4792`, and reads any required credentials from v3 semantics-free secrets. The image default entrypoint starts the service.

## Acceptance Criteria
- [ ] The official image starts a Runtime Service on `0.0.0.0:8080`.
- [ ] The image can accept a prompt through `/exec` and produce a terminal Run Result.
- [ ] The image can serve a generated app preview on `0.0.0.0:4792`.
- [ ] Agent/model/provider details are not represented in the MoonCraft Runtime Manifest.
- [ ] Multi-architecture build and publish flow is updated for the v3 image.
