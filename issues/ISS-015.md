## Description
Replace fixed preview port proxying with proxying to the Runtime Service `/preview/` subtree on the same HTTP service as Runtime Protocol APIs.

## Design
MoonCraft should route the user's Preview Origin path `/...` to the Runtime Service path `/preview/...`. The Runtime Service owns preview content and readiness. MoonCraft should not know or store a preview port, should not call a separate preview readiness endpoint, and should surface Runtime preview errors without preview repair prompts.

## Acceptance Criteria
- [ ] Public Preview Origin root proxies to Runtime Service `/preview/`.
- [ ] Public Preview Origin subpaths proxy to matching Runtime Service `/preview/...` subpaths.
- [ ] Fixed port `4792` is removed from the active preview target model.
- [ ] Successful preview requests refresh Runtime Idle TTL.
- [ ] Tests cover root, asset subpath, Runtime preview error, and stopped-service lazy recovery.
