# ISS-014: Require Ready Source Commit for successful Runs

## Metadata
- Type: feature
- Status: open

- Assignee: unassigned
- Created: 2026-05-30
- Updated: 2026-05-30
- External ref: docs/runtime-protocol/openapi.v3.yaml

## Description
Update run execution so a source-modifying Run only succeeds after the Runtime Service commits and pushes source changes to the Project Source Repository default branch and returns the final pushed Ready Source Commit.

## Design
Extend Runtime Run result handling to require `ready_commit_sha` on `succeeded`. Store that commit as the project's current Ready Source Commit. Treat missing commit, push conflict, or source repository errors as non-ready terminal failures. The Runtime may create multiple commits internally, but MoonCraft records only the final pushed commit.

## Acceptance Criteria
- [ ] `GET /runs/{run_id}` succeeded responses require and parse `ready_commit_sha`.
- [ ] MoonCraft stores the final Ready Source Commit on project success.
- [ ] Missing `ready_commit_sha` from a succeeded Runtime Run is treated as a protocol error.
- [ ] Source conflicts or push failures do not leave the project marked Ready.
- [ ] Tests cover success with commit, success missing commit, failure/conflict, and project commit update.
