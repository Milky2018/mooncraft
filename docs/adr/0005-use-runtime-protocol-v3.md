# Use Runtime Protocol v3

Runtime Protocol v3 supersedes ADR-0002, ADR-0003, and ADR-0004. MoonCraft will treat a Runtime as a project-scoped HTTP service instead of a control-plane-owned Codex or Claude adapter: Runtime manifests contain only `protocol_version`, `image`, semantics-free `env`, and semantics-free `secrets`; the Runtime image starts its own service on port `8080`; the project preview is served from fixed container port `4792`; `/workspace` and `/home/mooncraft` are MoonCraft-managed Docker volumes; and MoonCraft communicates through the v3 OpenAPI instead of agent-specific commands, prompt files, result files, or preview scripts. This deliberately moves agent/model/session/user details behind the Runtime image boundary while keeping MoonCraft responsible for project state, chat history, event persistence, public preview origins, and Runtime lifecycle policy.
